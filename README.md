# THE CHAMP BOXING GYM — 웹사이트

분당 서현동 **더챔프 복싱장** 원페이지 웹사이트입니다.
전화 문의 없이 손님이 스스로 확인할 수 있도록 **처음 3초 안내 → 4가지 이유 → 실제 수업 영상 →
회원 사진 → 프로그램 → 코치진 → 커뮤니티 → 요금 상담 → 시간표 → FAQ → 오시는 길**을
한 페이지에 담았고, 모든 문의는 **카카오톡 채널**로 모이도록 설계했습니다.

파일은 `index.html` 하나로 완결됩니다(별도 빌드·서버 불필요).

**현재 공개 주소: https://ballsy69.github.io/the-champ-boxing/** (실제 배포처)

### 카카오톡 채널 연결법
1. [카카오톡 채널 관리자센터](https://center-pf.kakao.com)에서 채널 개설
2. 채널 홈 URL 복사 (예: `https://pf.kakao.com/_abcDE`)
3. `index.html` 에서 `[수정] 카카오톡 채널` 주석을 찾아 `href="#contact"` 를 채널 주소로 교체하고,
   `onclick="return kakaoNotYet(event)"` 를 삭제
4. 플로팅 버튼(`kakao-float`)과 상단 "카톡 문의" 버튼의 `href` 도 같은 주소로 교체하면
   어디서 눌러도 바로 채팅으로 연결됩니다

## 2. 사진·영상 넣는 법

- **사진**: `images/` 폴더에 정해진 파일명으로 넣으면 자동 표시됩니다 (자세한 내용은 `images/README.md`).
  같은 파일명으로 덮어쓰면 사진이 교체됩니다.
- **영상**: `videos/` 폴더에 mp4 로 직접 넣는 방식으로 되어 있습니다(현재 `class-reel.mp4`,
  `entrance-reel.mp4`). 저녁 수업 영상이 도착하면 같은 방식으로 `videos/` 에 추가하고
  `#video` 섹션의 `[수정]` 주석 자리에 연결하면 됩니다.

- 컨셉: **화이트 + 비비드 블루** — 밝고 활기찬 톤(사장님 요청으로 어두운 톤/골드 톤에서 전환됨).
  섹션 순서는 사장님 브리프대로 히어로 → 4가지 이유 → 실제 수업 영상 → 회원 사진 →
  프로그램 → 코치진 → 커뮤니티 → 요금 상담 → 시간표 → FAQ → 오시는 길
- 사진 연출: 단체 사진은 섹션 배경에 흐리게(blur) 깔고, 수업·시설·커뮤니티 사진은
  손글씨 느낌 캡션이 달린 낱장 스냅(폴라로이드 느낌)으로 페이지 곳곳에 흩어서 배치
  (한 곳에 모아놓는 "졸업앨범" 그리드 방식은 지양)
  — 모바일에서는 스냅·영상이 화면 전체 폭에 가깝게 커지도록 처리됨
- 요금: 금액 비노출, 카카오톡 1:1 상담 유도 (사장님 요청)
- 서체: Do Hyeon(국문 헤드라인) · Big Shoulders(숫자·포스터) · Gaegu(사진 캡션) ·
  IBM Plex Sans KR(본문)
- 모바일 우선 반응형 (손님 대부분이 카카오톡·네이버 지도에서 모바일로 유입되는 것을 가정)
- 로고: 인스타그램 접근이 막혀 있어, 체육관 실제 시간표 포스터 사진에서 색상 분리 방식으로
  추출·재구성한 버전(v5)을 사용 중. 노이즈는 줄였지만 이 환경에는 진짜 생성형 AI 업스케일
  도구가 없어 원본 벡터 로고와 동일하지는 않음 — 가능하면 디자이너의 원본 파일을 구해서
  교체하는 것을 권장
