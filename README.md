## 4. 디자인 노트 (2026-09-02 전면 개편)

- 서체: **Black Han Sans**(헤드라인 — 국내 스포츠·복싱 포스터의 정석, 체육관 자체 홍보물의 굵은 붓글씨 톤과 맞춤) ·
  **Noto Sans KR 500/700/900**(본문·UI, 본문 17px 이상, 글자색 거의 검정) · **Anton**(숫자·영문 라벨).
  이전의 Do Hyeon(가늘고 둥근 느낌)·Gaegu(손글씨)는 "케이크 가게 같다"는 피드백으로 전부 제거.
- 색 — **낮/밤 두 가지 화면**(상단 바의 🌙/☀️ 버튼): 낮 = 화이트 배경 + 골드(버튼·강조) + 검정 글씨, 밤 = 다크 배경(#0b0f14) + 블루(#1e5eff) + 흰 글씨.
  처음 접속 시 기기 시간이 19시~6시면 밤, 그 외는 낮으로 시작하고, 한 번 고르면 그 기기에 저장됩니다(`localStorage`).
  색은 전부 CSS 변수(`--accent`, `--bg`, `--ink` 등)라 `:root[data-theme="night"]` 블록만 고치면 밤 색을 바꿀 수 있습니다.
  검정은 사진 위 캡션 탭·첫 화면 태그에만 고정으로 쓰고, 본문 위의 칩(수업 순서·JTBC 배지)은 `--ink`/`--bg` 로 두 화면 모두 대비가 나오게 했습니다.
  ※ 사장님 서면 브리프는 "배경 화이트, 메인 컬러 선명한 블루"였습니다 — 낮 화면의 골드는 프로젝트 리드 요청이므로, 사장님께 낮 화면을 한 번 확인받는 것을 권합니다.
  블루로 되돌리려면 `:root` 의 `--accent:#f2c230; --accent-deep:#d9a90f; --accent-ink:#0b0f14; --accent-text:#8e6a00; --accent-text-lg:#a87a08; --chip-accent:#f2c230;` 를
  `--accent:#1e5eff; --accent-deep:#1246d6; --accent-ink:#fff; --accent-text:#1246d6; --accent-text-lg:#1e5eff; --chip-accent:#f2c230;` 로 바꾸면 됩니다.
- 배경 사진: 사장님 원칙("단체 사진은 흐리게 배경으로")대로 4가지 이유·프로그램·FAQ·오시는 길·문의 섹션 뒤에 단체 사진을 흑백·흐림·9~13% 투명도로 깔았습니다(`.bgp`).
- 복싱의 강함은 어두운 색·선수 이미지가 아니라 **굵은 글자 무게, 직선(둥근 모서리 없음), 큰 숫자(20분·30분·700kcal), 실제 훈련 영상**으로 표현
  — 사장님이 쓰신 "무겁고 강한 이미지보다는 깔끔·활기차·초보인 나도"와 충돌하지 않게.
- 순서: 첫 화면 → 4가지 이유 → 실제 60분 → 회원 → 프로그램 → **회원권(요금 상담)** → 코치진 → 커뮤니티 → 시간표 → FAQ → 오시는 길 → 문의.
  요금 상담은 프로그램 바로 다음, "얼마예요?"가 떠오르는 자리에 두었고 버튼은 문자(`sms:`) 문의로 연결(카카오톡 채널이 생기면 교체).
- 구조: 기울어진 폴라로이드 카드(.snap) 전부 제거. 사진은 화면 폭을 꽉 채우는 **띠(band)** 와 **2×2 그리드**, 시설은 모바일에서 옆으로 넘기는 타일 줄.
  체육관 홍보 포스터 이미지(01/02/03, 50분/700kcal 등)는 모바일에서 글씨가 안 읽혀 제거하고 그 **핵심 숫자만 큰 글자**로 남김.
  모바일 페이지 길이 약 20화면 → 약 12화면.
- 모바일 CTA: 화면을 가리던 플로팅 버튼 대신 **하단 고정 바**(무료체험 신청 | 전화 문의). 첫 화면 버튼이나 마지막 문의 버튼이
  보이는 동안은 자동으로 숨겨져 같은 버튼이 두 번 보이지 않습니다. 안전영역(홈 인디케이터) 반영.
- 한글 줄바꿈: `word-break:keep-all` 로 음절 중간에서 끊기지 않게, 헤드라인은 `text-wrap:balance`.
- 영상: 자동재생 영상은 화면 밖으로 나가면 멈추고(배터리·데이터), 저전력 모드 등으로 재생이 거부되면 포스터 사진만 보입니다.
- "준비 중" 같은 안내 문구는 공개 페이지에 노출하지 않고 HTML 주석(`[수정]`)으로만 남깁니다.
- 첫 화면: 사장님 요청("여성 회원이 운동하는 영상이 가장 먼저")대로 여성 회원이 코치의 보호대에 펀치를 넣는 릴스 장면이 주인공.
  모바일은 세로 영상을 가로폭에 맞춰(자막·인물이 안 잘리게) 천장만 살짝 잘라 배치하고 문구는 아래 그라데이션 위에, 데스크톱은 왼쪽 문구 + 오른쪽 세로 패널.
  영상 속 자막을 지우는 것도 시도했지만(인페인팅) 얼굴이 뭉개져서 두지 않았습니다 — 자막 없는 원본이 오면 그대로 교체하면 됩니다.
- 로고(v6): 소개 영상 엔딩 카드에서 71프레임 평균으로 노이즈를 지우고 확대·재구성 — 독수리 몸통·글러브까지 완전한 형태.
  디자이너 원본(벡터/PNG)을 구할 수 있으면 `images/logo.png` 를 그 파일로 덮어쓰는 것을 권장.
- 문의 버튼: 카카오톡 채널이 아직 없어 **네이버 예약(초록) · 전화 · 문자**로 연결. 채널이 생기면 1. 항목 참고.
- 네이버 리뷰 요약(`.nrev`): 평점·인원·키워드 숫자는 네이버 플레이스 화면 그대로, 출처와 날짜를 항상 함께 표기. 숫자가 바뀌면 이 블록만 갱신.
- 모바일 우선 반응형. 손님 대부분이 카카오톡·네이버 지도에서 삼성 인터넷/사파리로 유입되는 것을 가정.
