회원 사진 → 프로그램 → 코치진 → 커뮤니티 → 요금 상담 → 시간표 → FAQ → 오시는 길**을
한 페이지에 담았고, 모든 문의는 **카카오톡 채널**로 모이도록 설계했습니다.

파일은 `index.html` 하나로 완결됩니다(별도 빌드·서버 불필요).

**현재 공개 주소: https://ballsy69.github.io/the-champ-boxing/** (실제 배포처)

### 카카오톡 채널 연결법
1. [카카오톡 채널 관리자센터](https://center-pf.kakao.com)에서 채널 개설
2. 채널 홈 URL 복사 (예: `https://pf.kakao.com/_abcDE`)
3. `index.html` 에서 `[수정] 카카오톡 채널` 주석을 찾아 `href="#contact"` 를 채널 주소로 교체하고,
   `onclick="return kakaoNotYet(event)"` 를 삭제
4. 모바일 하단 고정 바(`.ctabar`)의 "카톡 문의" 버튼과 첫 화면 "카카오톡 문의하기" 버튼의 `href` 도
   같은 주소로 교체하면 어디서 눌러도 바로 채팅으로 연결됩니다

## 2. 사진·영상 넣는 법

- **사진**: `images/` 폴더에 정해진 파일명으로 넣으면 자동 표시됩니다 (자세한 내용은 `images/README.md`).
  같은 파일명으로 덮어쓰면 사진이 교체됩니다.
- **영상**: `videos/` 폴더에 mp4 로 직접 넣는 방식입니다(현재 `hero-reel.mp4`, `class-60.mp4`,
  `welcome.mp4`, `entrance-reel.mp4`). 저녁 수업 영상이 도착하면 `class-60.mp4` 를 교체하거나
  `#sixty` 섹션의 `[수정]` 주석 자리에 연결하면 됩니다.

## 4. 디자인 노트 (2026-09-02 전면 개편)

- 서체: **Black Han Sans**(헤드라인 — 국내 스포츠·복싱 포스터의 정석, 체육관 자체 홍보물의 굵은 붓글씨 톤과 맞춤) ·
  **Noto Sans KR 500/700/900**(본문·UI, 본문 17px 이상, 글자색 거의 검정) · **Anton**(숫자·영문 라벨).
  이전의 Do Hyeon(가늘고 둥근 느낌)·Gaegu(손글씨)는 "케이크 가게 같다"는 피드백으로 전부 제거.
- 색: 배경 화이트, 메인 블루(버튼·강조), 글씨 검정 — 사장님 브리프 그대로. 검정은 사진 캡션 탭·첫 화면 태그·굵은 괘선처럼
  작은 요소에만 쓰고, **검정 배경 섹션은 두지 않습니다**(사장님이 어두운 톤을 명확히 거절하셨기 때문). 로고 골드는 로고·티커 별·JTBC 글자에만.
- 복싱의 강함은 어두운 색·선수 이미지가 아니라 **굵은 글자 무게, 직선(둥근 모서리 없음), 큰 숫자(20분·30분·700kcal), 실제 훈련 영상**으로 표현
  — 사장님이 쓰신 "무겁고 강한 이미지보다는 깔끔·활기차·초보인 나도"와 충돌하지 않게.
- 순서: 첫 화면 → 4가지 이유 → 실제 60분 → 회원 → 프로그램 → **회원권(요금 상담)** → 코치진 → 커뮤니티 → 시간표 → FAQ → 오시는 길 → 문의.
  요금 상담은 프로그램 바로 다음, "얼마예요?"가 떠오르는 자리에 두었고 버튼은 카카오 노란색(문의 버튼과 동일한 동작).
- 구조: 기울어진 폴라로이드 카드(.snap) 전부 제거. 사진은 화면 폭을 꽉 채우는 **띠(band)** 와 **2×2 그리드**, 시설은 모바일에서 옆으로 넘기는 타일 줄.
  체육관 홍보 포스터 이미지(01/02/03, 50분/700kcal 등)는 모바일에서 글씨가 안 읽혀 제거하고 그 **핵심 숫자만 큰 글자**로 남김.
  모바일 페이지 길이 약 20화면 → 약 14화면.
- 모바일 CTA: 화면을 가리던 플로팅 버튼 대신 **하단 고정 바**(무료체험 신청 | 카톡 문의). 첫 화면 버튼이나 마지막 문의 버튼이
  보이는 동안은 자동으로 숨겨져 같은 버튼이 두 번 보이지 않습니다. 안전영역(홈 인디케이터) 반영.
- 한글 줄바꿈: `word-break:keep-all` 로 음절 중간에서 끊기지 않게, 헤드라인은 `text-wrap:balance`.
- 영상: 자동재생 영상은 화면 밖으로 나가면 멈추고(배터리·데이터), 저전력 모드 등으로 재생이 거부되면 포스터 사진만 보입니다.
- "준비 중" 같은 안내 문구는 공개 페이지에 노출하지 않고 HTML 주석(`[수정]`)으로만 남깁니다.
- 첫 화면: 사장님 요청("여성 회원이 운동하는 영상이 가장 먼저")대로 회원의 헤비백 훈련 영상이 주인공.
  모바일은 세로 영상이 화면을 가득 채우고 문구가 아래 흰 그라데이션 위에, 데스크톱은 왼쪽 문구 + 오른쪽 세로 패널.
- 로고(v6): 소개 영상 엔딩 카드에서 71프레임 평균으로 노이즈를 지우고 확대·재구성 — 독수리 몸통·글러브까지 완전한 형태.
  디자이너 원본(벡터/PNG)을 구할 수 있으면 `images/logo.png` 를 그 파일로 덮어쓰는 것을 권장.
- 모바일 우선 반응형. 손님 대부분이 카카오톡·네이버 지도에서 삼성 인터넷/사파리로 유입되는 것을 가정.
